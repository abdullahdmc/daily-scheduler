Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: this project has applied to SignPath Foundation. Signing starts with the first release after the application is approved, and this note will be removed then.

Windows installers of Daily scheduler are signed so that Windows can confirm they come from this project and haven't been changed. Signed files are built only from the public source code in the GitHub repository by its GitHub Actions release workflow. Every release is approved by hand before it's signed.

Team roles

  • Committers and reviewers: Md Abdullah Saeed Khan. Changes from anyone outside the team are reviewed before they're merged.
  • Approvers: Md Abdullah Saeed Khan.

The current list of people with write access is on the repository's contributors page. All team members use multi-factor authentication for GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user. The only network connection the app makes is to Google, and only when you choose to sign in with Google to sync with Google Tasks. See the privacy policy for details.

System changes

The app sets itself to open when you log in. It tells you this the first time it starts, with a button to turn it off, and you can change it at any time in Settings. Uninstalling removes this setting.
